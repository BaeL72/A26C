                           group automatically

### Ownership - chown/chgrp

chown alice file.txt Change owner of file to alice
chown alice:devs file.txt Change owner and group
chgrp devs file.txt Change group only
chown :devs file.txt Change group only
chown -R alice:devs /project/ Recursive
chown --reference=ref.txt target.txt Copy ownership from another file

Setuid(SUID) - bit 4 On executables: runs as the file owner, not the caller.
chmod u+s /usr/bin/passwd
chmod 4755 file

Setgid(SGID) - bit 2 On executables: runs as the file's group. On directories: new files
inherit the directory's group.
chmod g+s /shared/dir
chmod 2755 /shared/dir

Sticky bit - bit 1 On directories: users can only delete their own files even if they have
write on the dir. Used on /tmp.
chmod +t /tmp
chmod 1777 /tmp

setfacl -m u:alice:rw rile.txt Grants user alice read+write
setfacl -m g:devs:r file.txt Grants group devs read only
setfacl -m u:alice:rw,g:devs:r file.txt Multiple rules at once
setfacl -R -m u:alice:rwx /project/ Recursive
setfacl -x u:alice file.txt Remove one entry
setfacl -b file.txt Remove all ACLs
setfacl -d -m u:alice:rw /project/
setfacl -k /project/ Remove all defaults
getfacl file.txt
Backup and restore:
getfacl -R /project/ > acls.bak
setfacl --restore=acls.bak

umask - Default permission mask. Defines which bits are removed from new files/dirs.
        When create a new file or directory, the system applies a umask to strip certain
        permissions automatically.
        Define what to take away from new files, not what give.

umask Show current(octal)
umask -S Show current(symbolic)
umask 027 Set new umask

file default: 666
umask: -022
result: 644
